# Daniel Joy — Portfolio

Source for [danieljucke.github.io/Portfolio](https://danieljucke.github.io/Portfolio/).

This is a lightweight, static portfolio focused on verified public projects. It uses semantic HTML and a small embedded stylesheet, with responsive layouts, keyboard focus styles, dark-mode support, and reduced-motion support.

## Preview locally

No build step or package installation is required.

```bash
python -m http.server 8000
```

Open <http://localhost:8000>.

## Deployment

GitHub Pages publishes the default branch. Changes should be reviewed in a pull request before they reach the live site.
